# Zaza Reader 0.6.19-preview

Улучшена работа с большой библиотекой: просмотр карточки больше не добавляет произведение автоматически, уточнены счётчики импорта, список прокручивается без кнопок «Следующие 40» и сохраняет поиск, фильтры и позицию. Синхронизация сначала отправляет изменённый прогресс, пропускает недавно проверенные позиции и продолжает импорт частями. Минимальная версия — Android 13.

- Старые записи библиотеки, скачанные главы и прогресс сохраняются. Новое произведение можно добавить явно или импортировать из аккаунта.
- Поиск работает по всей библиотеке; возврат из произведения и фоновое обновление прогресса сохраняют место прокрутки.
- Повторная проверка свежих позиций откладывается на 10 минут. Конфликты и неудачные запросы обрабатываются отдельно.
- В синхронизации показаны отдельные счётчики библиотеки, закладок аккаунта и позиций чтения. Неподдерживаемые записи сайта учитываются отдельно.
- Поддержка Android 9–12 прекращена. Один APK для Android 13 и новее; оба JSON нужны существующим обновляторам и содержат одинаковый минимум Android 13.

Установите обновление поверх 0.6.18-preview: удалять приложение не нужно. Обновление доступно через Ещё → Настройки → Обновление приложения.
