# Zaza Reader 0.6.18-preview

Исправлено отображение версии приложения: настройки и экран обновлений получают фактическую версию установленного APK из одного источника. После обновления старая подпись версии больше не сохраняется.

Android 9 и новее. Первую версию с обновлятором установите поверх прежней. Дальше: Ещё → Настройки → Обновление приложения.
