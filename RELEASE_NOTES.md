# Zaza Reader 0.6.13-preview

Читалка: постраничный режим с горизонтальными взмахами, непрерывная вертикальная лента, предзагрузка скачанных изображений, сохранение страницы и позиции внутри неё, общий масштаб для глав произведения. Настройки: Ещё → Настройки → Чтение.

Android 9 и новее. Первую версию с обновлятором установите поверх прежней. Дальше: Ещё → Настройки → Обновление приложения.
