# Zaza Reader — публичные обновления

Здесь размещаются APK, update.json и update-android9.json. Исходники находятся в приватном репозитории zaza-reader.

Релиз: v0.6.11-preview. Вложения: ZazaReader-0.6.11-preview.apk, update.json и update-android9.json. Опубликовать как Latest, без Draft и без отметки Pre-release: обновлятор использует каналы releases/latest/download/update.json (старые версии) и update-android9.json (0.6.10 и новее). Preview в имени версии означает тестовую сборку приложения.
